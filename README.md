# 터미널 농장 — 내 코딩 에이전트 대화창을 한눈에

이 컴퓨터에서 돌아가는 코딩 에이전트 대화창(클로드 코드·코덱스 등) 하나하나가 **농장의 일꾼**입니다.
레포 하나가 **땅 한 필지**이고, 땅의 종류는 업무 성격을 따릅니다. 서로를 쓰는 레포는 **흙길과 수로**로 이어집니다.
나를 기다리는 대화창은 일꾼 머리 위에 **느낌표 말풍선**이 뜨고, 농가 **우편함 깃발**이 섭니다.
일꾼을 눌러 **[열기]**를 누르면 그 대화창이 원래 프로그램에서 열립니다.

> **[Bot Crossing](https://github.com/station-sciences/bot-crossing)(Jarren Rocks 작)을 고친 판입니다.**
> 대화창을 읽어 오는 서버 쪽은 원작 그대로이고, 화면을 3D 우주 기지에서 2D 픽셀 농장으로 새로 만들었습니다.
> 원작과 무관하며 원작자가 보증하지 않습니다. 상표 규칙: [TRADEMARKS.md](TRADEMARKS.md).

> **있는 그대로 공개합니다.** 제가 쓰려고 만든 것을 그대로 올렸습니다. 질문이나 문제 제보에 답을 못 드릴 수 있습니다.
> 마음대로 고쳐 쓰셔도 됩니다(MIT 라이선스).

## 설치 — 클로드 코드에 한 줄

클로드 코드에 아래 한 줄을 붙여 넣으세요. 에이전트가 [INSTALL.md](INSTALL.md)를 읽고 순서대로 설치합니다.

```text
github.com/ceokobec-hue/terminal-farm 의 INSTALL.md 를 읽고 그대로 설치해 줘
```

- 시작하기 전에 할 일을 먼저 보여 주고 허락을 받습니다. 내 설정 파일을 바꾸기 전에는 백업하고 한 번 더 묻습니다.
- 설치 중에 묻는 것은 하나뿐입니다 — 「모델·컨텍스트 정보 줄을 켤까요?」(아래 「정보 줄 켜기」).
- 무엇을 하는지 미리 보려면 [INSTALL.md](INSTALL.md)를 열어 보세요. 에이전트가 하는 일은 거기 적힌 것이 전부입니다.

## 직접 설치하기

```bash
git clone https://github.com/ceokobec-hue/terminal-farm.git
cd terminal-farm && npm install
scripts/start.sh        # 맥: 서버를 켜고 브라우저로 http://localhost:5274 를 엽니다
```

- `npm install` 때 `npm warn install-scripts …` 노란 경고가 나와도 **정상**입니다(최근 npm 의 안전 안내). 승인하지 말고 그대로 다음 줄로 가세요.
- **윈도우·리눅스**: 마지막 줄 대신 `npm start` 를 실행하고 브라우저로 http://localhost:5274 를 여세요. 그 창을 닫으면 농장도 꺼집니다.
- Node 22.13 이상. **macOS Terminal 앱**에서 [터미널로 가기](탭 이동)·[새 대화](새 탭)까지 다 됩니다.
  다른 터미널·운영체제에서는 농장을 **보는 것**은 되고, 탭을 옮겨 주는 기능은 아직 없습니다.
- 끄기: `scripts/stop.sh` · 서버 기록: `data/server.log` · 시험: `npm test` · 개발: `npm run dev`
- **Terminal 안에서 켜세요.** [터미널로 가기]가 탭 막대의 탭을 누르려면 맥 「손쉬운 사용」 권한이 필요한데,
  Terminal에서 켠 서버는 Terminal의 권한을 그대로 물려받습니다. 처음 누를 때 맥이 권한을 물으면 허용하세요.
- 내 아이콘을 쓰려면 `data/favicon.png`(와 `data/apple-touch-icon.png`)를 넣으면 기본 농부 대신 그 그림이 뜹니다.

### (선택) 모델·노력·컨텍스트 정보 줄 켜기

일꾼 아래 「🐮 Opus · 힘★★★★ · 🤖 자동 · 🧠 52%」와 시계 상자의 요금제 사용량은 클로드 코드의 **상태줄(statusline)** 이
알려 주는 값입니다. 클로드 코드 설정 파일(`~/.claude/settings.json`)의 상태줄을 이 저장소의 `scripts/statusline.mjs` 로
연결하면 세션마다 그 값이 `~/.claude/terminal-farm-status/` 에 저장되고 농장이 읽어 갑니다(밖으로 보내는 것은 없습니다).
설정 파일은 바꾸기 전에 복사해 두세요.

- **상태줄을 쓰고 있지 않으면** — 「모델 · 🧠 컨텍스트 %」 짧은 상태줄이 생깁니다.

  ```json
  "statusLine": { "type": "command", "command": "node \"/설치한/폴더/terminal-farm/scripts/statusline.mjs\"" }
  ```

- **이미 상태줄이 있으면(맥·리눅스)** — 화면의 상태줄은 그대로 두고 값만 함께 저장합니다. 원래 `command` 를
  `data/statusline-wrap.json` 에 `{ "command": "원래 명령" }` 으로 옮기고, `command` 를
  `node "/설치한/폴더/terminal-farm/scripts/statusline.mjs" --wrap` 으로 바꿉니다.

넣지 않아도 농장은 돌아갑니다 — 그때는 컨텍스트를 대화 기록으로 **추정**해서 보여 줍니다.

## 무엇이 보이나 — 기본은 「터미널에 띄운 것만」

지금 **터미널에 열려 있는 클로드 코드 세션만** 일꾼이 됩니다(맥 앱에서 연 것, 이미 닫힌 것은 빠짐).
세션 상태는 클로드 코드가 직접 적어 두는 값을 씁니다 — `busy` = 일하는 중, 그 밖 = 내 차례(입력을 기다림).
일꾼의 **[터미널로 가기]** 는 새 창을 띄우지 않고 **그 세션이 돌고 있는 Terminal 앱 탭을 앞으로** 가져옵니다
(같은 대화를 두 번 열면 엉키기 때문). 땅의 **[새 대화]** 는 세션들이 있는 Terminal 탭 막대에 **새 탭**을 열고 `claude` 를 그 폴더로 엽니다.
설정 → 「보여 줄 대화창: 앱 포함 전부」로 바꾸면 예전처럼 앱 대화창까지 다 보입니다.

> 처음 [터미널로 가기]를 누를 때 macOS가 "Terminal을 제어하도록 허용할까요?"를 물을 수 있습니다 — 허용해야 탭이 앞으로 옵니다.

## 한눈에 보는 것들

- **지금 일하는 땅** — Terminal 탭 하나에 땅 하나, 탭 순서대로 왼쪽 위에 놓입니다. 위 이름표는 탭 이름(`/rename` 하면 바뀜),
  아래 「📍」 푯말은 그 터미널이 일하는 레포입니다. 탭마다 색이 있어 트랙터·도우미 모자도 같은 색입니다.
- **트랙터 🚜** — 터미널이 다른 레포를 가져다 쓰면(최근 1시간·이번 차례, 스킬·메모리 창고는 빼고) 그 탭 색깔 트랙터가 생깁니다.
  일하는 동안은 레포 땅 ↔ 터미널 땅을 흙길로 오가며 짐(상자)을 나르고, 쉬는 동안은 레포 땅에 세워 둡니다.
  터미널 땅 「🚜」 푯말·현황판·일꾼 상자에 그 레포 이름과 한 일(수정·읽기·실행 횟수)이 나옵니다.
- **🥕 컨텍스트 밭** — 터미널 땅의 작물은 그 세션의 컨텍스트입니다. 5%마다 한 칸씩 심기고 먼저 심은 칸부터 자라며,
  80%를 넘으면 「곧 압축」 깃발이 섭니다. 땅 왼쪽 **상자 = 압축(대화를 요약해 비운) 횟수**(톱니 = 자동, 손 = 직접 /compact).
  압축되는 순간 작물이 상자로 들어가는 장면이 한 번 나옵니다.
- **📜 규칙 게시판** — 터미널 땅 옆 게시판 = 그 세션이 실제로 읽은 규칙 파일(전역 `~/.claude/CLAUDE.md` → 폴더 → 레포의
  `CLAUDE.md`·`AGENTS.md`, 메모리 목차). 대화 기록에 남은 것만 보여 줍니다. 농가의 큰 게시판 = 전역 규칙.
- **🧭 구조 투어(T)** — 일꾼 → 땅 → 게시판 → 창고 → 트랙터 → 계기판 → 전체 순서로 화면이 따라가며 비춥니다(← → 넘기기).
- **🗺 대응표(K)** — 왼쪽 아래 「농장 = 실제」 표.
- **레포 땅의 도우미** — 터미널이 쓰는 레포 땅(일하는 레포 📍, 가져다 쓰는 레포 🚜)에는 그 탭 색 모자를 쓴 도우미가 서고,
  터미널이 일하는 동안 계속 왔다갔다 합니다. 레포 이름표 끝에 「📍탭2」「🚜탭1」처럼 누가 쓰는지 붙습니다.
- **터미널 현황판**(오른쪽, **B**) — 탭마다 상태(작업 중 / 내 차례), 지금 하는 일("파일 수정: render.js"),
  진행도(클로드가 할 일 목록을 만들었으면 `3/5` 막대, 아니면 "이번 차례 6분째 · 단계 17개"), 마감일.
- **마감** — 현황판이나 일꾼 상자에서 날짜를 고르면 `D-2`·`오늘 마감`·`마감 지남`으로 표시(대화 기록엔 마감이 없어서 직접 정함).
- **심부름꾼** — 최근 10분 사이 스킬·메모리 창고를 쓰면, 짐을 든 심부름꾼이 길을 따라 오가며
  "스킬: insert-order", "메모리 기록: …" 이름표를 보여 줍니다(다른 레포는 트랙터가 맡음).
- **정보 줄** — 일꾼 아래 「🐮 Opus 5.5 · 힘★★★★ · 🤖 자동 · 🧠 52% (518k)」: 모델(소=Opus·양=Sonnet·병아리=Haiku·유니콘=Fable)·
  노력(별 1~5)·권한 모드·컨텍스트. 멀리서 보면 「🐮★★★★ 🤖 52%」 아이콘으로 줄어듭니다.
- **확대·축소** — 트랙패드 핀치는 부드럽게 확대·축소, 두 손가락 쓸기는 이동, 마우스 휠은 한 칸씩. 멈추면 선명한 배율로 맞춰짐.
  새로 열면 늘 기본 3배로 시작합니다(배율은 저장하지 않음 — 화면이 새 버전으로 바뀔 때만 그대로 유지).
- 레포 이름표는 화면 글씨라 어떤 배율에서도 같은 크기로 보입니다.
- **새 대화** — 땅을 고르고 [새 대화](**C**)를 누르면 그 레포에서 클로드 코드가 **Terminal 새 탭**으로 열리고(세션들이 있는
  탭 막대에 붙음), 화면이 새 터미널 땅으로 옮겨 갑니다.

## 보는 법

| 농장에서 | 내 일에서 |
| --- | --- |
| 땅 한 필지 | 레포 하나 (또는 레포 밖 작업 폴더) |
| 땅 종류 | 업무 성격 — 밭=강의·교육 · 과수원=영상·이미지 · 장터=SNS·홍보 · 헛간=업무 운영 · 대장간=도구·스킬 · 숲=실험·신사업. 이름으로 추정하고, 땅을 눌러 바꿀 수 있음 |
| 밀짚모자 일꾼 / 모자 없는 일꾼 | 클로드 코드 대화창 / 코덱스 대화창 |
| 느낌표 말풍선 · 우편함 깃발 | 내 차례 — 터미널이 내 입력을 기다림 (「확인함」을 누르면 다음 상태 변화까지 조용해짐) |
| 삽을 든 일꾼 | 일하는 중 |
| 트랙터(탭 색) | 그 탭이 다른 레포를 가져다 쓰는 중 — 짐을 싣고 터미널 땅으로, 빈 수레로 다시 레포로 |
| 색 모자 도우미 | 그 탭이 쓰는 레포 땅에서 일하는 중 |
| 병아리 | 보조 일꾼(서브에이전트) |
| 흙길 / 파란 수로 / 징검돌 | 다른 레포의 파일을 가져다 씀 / 다른 레포의 사이트·데이터를 같이 씀 / 약한 연결 |
| 농가 | 어느 레포에서 일했는지 확실히 알 수 없는 대화창 |

**대화창이 어느 땅에 서는지.** `~/repos` 처럼 레포들을 담은 폴더에서 연 대화창은, 대화 기록에 가장 많이 나온 레포의
땅으로 갑니다(3번 이상, 30% 이상일 때만). 기록이 분명하지 않으면 농가에 둡니다. 대화창 정보 상자에 어떻게 정했는지가 나옵니다.

**레포 연결을 찾는 법.** 한 레포의 코드가 다른 레포를 `~/repos/<이름>/…` 경로로 부르거나, 다른 레포의 Firebase 프로젝트 ID·
`*.web.app` 주소를 쓰면 연결입니다. 문서·보고서에서 이름만 나온 것은 그리지 않고, 모든 레포를 언급하는 메모 저장소는
빼며, 다른 프로젝트로 배포를 **막으려고** 적은 줄은 세지 않습니다. 근거 파일과 줄 번호는 땅을 누르면 나옵니다.

## 조작

끌어서 이동 · 휠로 확대 · **N** 다음 내 차례 · **C** 새 대화 · **J** 일지(전체 목록) · **L** 길·수로 · **0** 전체 보기 ·
**B** 현황판 · **H** 숨긴 땅 · **M** 소리 · **S** 설정 · **?** 보는 법 · **Z** 잠든 대화창 · **+/−** 확대·축소 · **Esc** 닫기.
아래 도구 막대 칸 모서리 글자가 그 칸의 단축키입니다.

## 읽는 것과 쓰는 것

| | |
| --- | --- |
| 읽음 | 각 프로그램의 대화 기록, 그리고 레포 폴더의 설정·코드 파일(연결 찾기) |
| 씀 | `data/colony.json` 하나뿐 (땅 종류·보관·확인함·숨긴 땅·설정) |
| 보냄 | 없음. 외부 통신·계정 없음 |

`127.0.0.1` 에만 붙고, 자기 페이지가 아닌 요청(다른 사이트, 다른 Host)은 거절합니다. 원작의 보안 설명은
[원작 README의 "Keeping it local"](https://github.com/station-sciences/bot-crossing#keeping-it-local)과 같습니다.
`data/colony.json` 에는 레포 이름과 경로가 들어 있으니 남에게 보내지 마세요(이미 git 제외 목록에 있음).

## 지원하는 프로그램

원작과 같습니다 — 클로드 코드, 코덱스, OpenCode, Antigravity CLI, Cursor, Hermes, Kilo Code.
「터미널에 띄운 것만」 보기에서는 실행 중인 세션 기록이 있는 **클로드 코드 CLI** 와, 다른 프로그램의 **CLI에서 시작한** 대화창만 나옵니다.
코덱스는 맥 앱·확장(`vscode`), 다른 도구가 부른 일회성 실행(`exec`), 맥 앱 내부 보조 작업(`subagent`)을 구분해 빼고,
터미널에서 `codex` 로 연 것만 남깁니다(코덱스 CLI는 "내 차례" 판정이 없어 일하는 중 / 쉬는 중만).
새 프로그램 붙이는 법: [`server/harnesses/README.md`](server/harnesses/README.md).
